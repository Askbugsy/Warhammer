Spyre Hunters

Gangs of the Outlands, Spyre Hunters. This book doesn't give fighter stat blocks for the Spyre Hunters. Their fighters are built from the core composition rules in the Necromunda Skirmish book, with the Spyrer subtype applied. Rule text is summarised in my own words.

The Spyrer subtype

  • Kill Count: each Spyrer's hunting rig keeps a Kill Count. It goes up by 1 each time that Spyrer takes an enemy fighter Out of Action, in addition to the XP it earns. The count unlocks the rig's functions and weapons.
  • Threat Assessment: when choosing starting crews or reinforcements, divide the models allowed by two and round up. That's how many Spyrers you can pick. For example, if three reinforcements would arrive, only two Spyrers arrive.

Master of the Hunt

  • All Spyrers have the Juggernaut skill.
  • A Spyrer can never be Captured. It suffers Superficial Damage instead (see the rulebook, page 69).
  • Spyrers don't suffer side effects from chems and can never become addicted to them.
  • A Spyrer never needs to make Nerve checks.
  • Reflex Enhancers: in the Ready Gang step of the Priority phase, each Spyrer gains one extra Ready marker. If something would stop it gaining a marker, it gains one fewer. Each time a Spyrer activates it removes only one Ready marker, so it can activate twice a round. Any effect that removes or blocks Ready markers only affects one of them.

Base of Operation and territory

Instead of starting with a Settlement, a Spyre Hunting Party starts with a Spyrer Base Camp territory, which it can never lose.

  • Income: the gang earns 15 credits from this territory when collecting income.
  • Special: at the start of each post-cycle sequence, one Spyre can clear its In Recovery box before declaring post-cycle actions.

Hunting rig augmentations

Each rig improves with three tiers. The tiers below are as printed on the equipment reference pages.

  • Paired bolt launchers: T1 Lethality 2. T2 AP -2. T3 Rapid Fire (3).
  • Paired disintegration matrix: T1 AP -3. T2 Ammo (4+). T3 Lethality 3.
  • Jakara hunting rig: T1 Strength +1. T2 Attacks +1.
  • Malcadon hunting rig: T1 BS or WS +1. T2 Save +1.
  • Malcadon slashing claw(s): T1 AP -3. T2 Lethality 2. T3 Strength S+1.
  • Malcadon toxin whip(s): T1 Lethality 2. T2 Paired (3). T3 Toxin (2+).
  • Mirror shield: T1 6+ invulnerable save. T2 Long Range 12″. T3 5+ invulnerable save.
  • Monomolecular sword: T1 Lethality 2. T2 AP -3. T3 Strength S+2.
  • Naga blade: T1 Shock (6+). T2 AP -2. T3 Lethality 3.
  • Yeld hunting rig: T1 Movement +1″. T2 +1 to Save rolls against shooting while in cover.
  • Yeld laser gauntlet(s): T1 AP -2. T2 Long Range 24″. T3 Strength 4.
  • Yeld missile gauntlet(s): T1 AP -1. T2 Strength 6. T3 Blast (3″).
  • Yeld wings: T1 Parry. T2 Lethality 2. T3 Knockback (6+).
